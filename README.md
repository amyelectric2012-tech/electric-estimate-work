# Electric Estimate Work

Production-oriented Next.js baseline for an electrical contractor estimating workflow in Los Angeles.

Included: dashboard, client CRM, estimate builder, editable material seed data, NEC section references/field notes, responsive UI.

Production work still required: authenticated persistence, real permit fee data, supplier pricing, PDF generation, audit logging, role-based access, and validation against the currently adopted NEC edition and Los Angeles/AHJ amendments.
